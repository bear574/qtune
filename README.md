## ✨ Возможности

- **Мини-плеер у часов** — компактное безрамочное окно в правом нижнем углу, всегда поверх других окон. Перетаскивается мышью, позиция запоминается.
- **Глобальные горячие клавиши** — работают из любой программы. По умолчанию: `Ctrl+Alt+Space` (пауза), `Ctrl+Alt+Right/Left` (следующий/предыдущий), `Ctrl+Alt+F9` (мини-плеер). Все комбинации переназначаются в настройках.
- **Плейлисты** — создание, переименование, удаление. Переключение между плейлистами, поиск по трекам.
- **Аудио и видео** — поддержка MP3, WAV, FLAC, OGG, M4A, AAC, OPUS, WMA. Если добавить видеофайл (MP4, MKV, AVI, WEBM, MOV), приложение автоматически извлечёт звуковую дорожку через FFmpeg и добавит её в плейлист.
- **Обложки альбомов** — если в тегах файла вшита обложка, она отображается в главном окне и в мини-плеере.
- **Темы и язык** — тёмная и светлая темы, русский и английский интерфейс. Переключаются в настройках (`Ctrl+,`).
- **Системный трей** — приложение живёт в трее, не мешает работе. Клик по иконке — показать/скрыть мини-плеер. Меню трея: полное окно, управление воспроизведением, выход.
- **Сохранение состояния** — плейлисты, громкость, позиция мини-плеера и настройки сохраняются между запусками.

## 🚀 Установка (для пользователей)

### Вариант 1: Готовый установщик (рекомендуется)

1. Скачай `Qtune_Setup.exe` из раздела [Releases](https://github.com/bear574/qtune/releases).
2. Запусти установщик. Права администратора **не требуются** — установка идёт в папку пользователя.
3. По желанию отметь галочки «Создать ярлык на рабочем столе» и «Запускать при старте Windows».
4. Готово! Запускай Qtune из меню «Пуск» или с рабочего стола.

> **Важно:** при первом запуске Windows Defender / SmartScreen может показать предупреждение, так как установщик не подписан цифровым сертификатом. Нажми «Подробнее» → «Выполнить в любом случае».

### Вариант 2: Портативная версия

1. Скачай архив `Qtune_Portable.zip` из [Releases](https://github.com/bear574/qtune/archive/refs/tags/V.1.zip).
2. Распакуй в любую папку (например, на флешку).
3. Запусти `Qtune.exe` из распакованной папки.

## 🛠️ Сборка из исходников (для разработчиков)(Пока нет)

### Требования

- Windows 10/11 (64-bit)
- Python 3.10 или новее
- [Inno Setup 6](https://jrsoftware.org/isdl.php) (только для сборки установщика)

### Шаги

```bash
# 1. Клонируй репозиторий
git clone No
cd qtune

# 2. Создай виртуальное окружение
python -m venv .venv
.venv\Scripts\activate

# 3. Установи зависимости
python -m pip install -r requirements.txt

# 4. Запусти в режиме разработки
python run.py
